## ✨ Sobre o Projeto

**Jogo de Luta** é um projeto escolar de um jogo de luta estilo arcade, com mecânicas simples de combate, personagens, cenários e efeitos visuais.

Tudo feito com **HTML5 + CSS3 + JavaScript Vanilla**, totalmente responsivo e com visual **roxo neon** dominante.

## 🚀 Funcionalidades

- ✅ **Combate em tempo real** (soco, chute, especial)
- ✅ **Dois personagens jogáveis**
- ✅ **Barra de vida** e barra de energia
- ✅ **Controles via teclado** (setas + Z, X, C)
- ✅ **Animações fluidas** com CSS e Sprite Sheets
- ✅ **Som e efeitos** (opcional)
- ✅ **Design totalmente roxo neon** com gradientes e glow
- ✅ **Tela de Menu, Seleção de Personagem e Game Over**
- ✅ **Responsivo** (funciona em desktop e mobile)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Canvas ou DOM)
- **CSS3** (Animações, Flexbox, Gradientes roxos, Glow effects)
- **JavaScript (Vanilla)**
- **Imagens e Sprites** customizados
- **Google Fonts** (fontes estilo gamer)
